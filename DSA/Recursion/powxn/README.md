## 📝 Problem Statement

Implement the power function pow(x, n) , which calculates the x raised to n i.e. **x** ^ **n** .

**Note** : In output print **6 digits** places after decimal point.

### Example 1

<p>

**Input:** x = 2.0000 , n = 10</p><p>

**Output:** 1024.0000</p><p>

**Explanation:** Answer = 2^10 => 1024.</p>

### Example 2

<p>

**Input:** x = 2.0000 , n = -2</p><p>

**Output:** 0.2500</p><p>

**Explanation:** Answer = 2^(-2) = 1/4 => 0.25.</p>

### Constraints

- -100.0 <= x <= 100.0
- -2^31 <= n <= 2^31 - 1
- -10^4 <= x^n <= 10^4
- Either x is not zero or n>0.
- n is an integer.

---

## 💡 Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N)$
- **Space Complexity:** $\mathcal{O}(1)$
